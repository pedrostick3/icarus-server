Este bot é usado num único servidor Discord privado, por um pequeno grupo de amigos. Mostra o estado do servidor do jogo, explica como entrar, publica backups do mundo e permite aos administradores reiniciar ou atualizar o servidor.

This bot is used in a single private Discord server by a small group of friends. It shows the game server status, explains how to join, posts world backups and lets administrators restart or update the server.
