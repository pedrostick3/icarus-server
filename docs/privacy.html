PT

Quem é responsável

O bot é mantido por um particular (o "administrador") para uso privado num único servidor Discord. Não há empresa, publicidade nem fins comerciais.

Que dados são tratados

Do Discord, quando usas um comando

  • O teu ID de utilizador, o nome que mostras no servidor e os teus cargos ou permissões. Servem apenas para verificar se podes usar comandos de administrador.
  • O comando que usaste e as opções que escolheste. O teu nome pode aparecer na mensagem de resultado no canal (por exemplo, "backup pedido por …").
  • A password dos comandos é escrita numa janela privada, comparada em memória e nunca guardada nem registada.
  • As tentativas de password falhadas (o teu ID e a hora) ficam em memória durante 15 minutos, para o bloqueio temporário. Ficam também registadas nos logs do servidor, com o teu nome e ID.

Do jogo

  • Os nomes dos jogadores ligados, obtidos pela consulta pública de servidores da Steam, são usados nas mensagens "entrou/saiu" do canal.
  • Os ficheiros de gravação do mundo podem incluir identificadores dos jogadores (por exemplo, o ID Steam). São guardados como backups.

Rede

O IP público da casa onde está o servidor é usado apenas para atualizar o serviço DuckDNS. Nunca é publicado no canal.

Onde ficam os dados

  • Computador do administrador: logs (com rotação, apagados automaticamente) e backups locais (até cerca de 6 meses, segundo a política de rotação).
  • Discord: mensagens e backups publicados no canal, até serem apagados.
  • Opcionalmente, uma cópia dos backups numa conta de armazenamento do administrador (por exemplo, Google Drive).

Os dados não são vendidos nem partilhados com terceiros, nem usados para publicidade ou análise. Os serviços usados para o bot funcionar são:

  • o Discord, que entrega as mensagens;
  • a Steam, para consultas e atualizações do jogo;
  • e, se estiverem ativos, o DuckDNS, o healthchecks.io e o armazenamento de backups. Este último recebe apenas os backups; o DuckDNS e o healthchecks.io não recebem dados pessoais.

Os teus direitos

Ao abrigo do RGPD, podes pedir para saber que dados existem sobre ti, ou para os corrigir ou apagar. Basta contactares o administrador no servidor Discord onde o bot está instalado. Também podes deixar de usar o bot a qualquer momento; sair do servidor Discord faz com que deixe de tratar os teus dados.

EN

Who is responsible

The bot is maintained by an individual (the "administrator") for private use in a single Discord server. There is no company, no advertising and no commercial purpose.

What data is processed

From Discord, when you use a command

  • Your user ID, server display name and roles or permissions. These are used only to check whether you may use administrator commands.
  • The command you used and the options you chose. Your name may appear in the result message in the channel (for example, "backup requested by …").
  • The command password is typed in a private pop-up, compared in memory and never stored or logged.
  • Failed password attempts (your ID and the time) are kept in memory for 15 minutes for the temporary lockout. They are also recorded in the server logs with your name and ID.

From the game

  • Names of connected players, obtained from the public Steam server query, are used in the channel's "joined/left" messages.
  • World save files may include player identifiers (for example, Steam IDs). They are stored as backups.

Network

The public IP of the home hosting the server is used only to update the DuckDNS service. It is never posted in the channel.

Where data is kept

  • The administrator's computer: logs (rotated and deleted automatically) and local backups (up to about 6 months, according to the rotation policy).
  • Discord: messages and backups posted in the channel, until deleted.
  • Optionally, a copy of the backups in the administrator's storage account (for example, Google Drive).

Data is not sold or shared with third parties, nor used for advertising or analytics. The services the bot needs to work are:

  • Discord, which delivers the messages;
  • Steam, for game queries and updates;
  • and, if enabled, DuckDNS, healthchecks.io and the backup storage. The storage receives only the backups; DuckDNS and healthchecks.io receive no personal data.

Your rights

Under the GDPR you may ask to know what data exists about you, or to have it corrected or deleted. Just contact the administrator in the Discord server where the bot is installed. You can also stop using the bot at any time; leaving the Discord server means it stops processing your data.
